This module gives every product created in the interface, or imported
without an XML ID, a predictable XML ID, so that it can be referenced in
imports and integrations without looking up its database id.

When a product is created, the module adds an XML ID
``product_template.<name>``, where ``<name>`` is made from:

- the internal reference of the product, for example ``FURN-0001``
  becomes ``product_template.furn_0001``;
- or, for products without an internal reference, its English name, for
  example *Desk Organizer (Large)* becomes
  ``product_template.desk_organizer_large``.

The name is lowercased, accents are removed, and every other character
than a letter or a digit is replaced by ``_``.

No XML ID is generated for products that already have one, such as
products imported with an *ID* column or loaded from data files, or when
the name is already used by another product; the latter is logged as a
warning.

Together with ``product_template_attribute_value_xmlid``, the attribute
values of these products get an XML ID too.

Use Cases / Context
===================

Products created in the interface get no XML ID. Imports and
integrations then have to reference them by database id, which differs
between databases, or by name, which is not unique.

``product_template_attribute_value_xmlid`` only names the attribute
values of products that have an XML ID, so the variants of these
products could not be referenced either.

Usage
=====

XML IDs are generated automatically when a product is created.

To generate the XML IDs of products that existed before the module was
installed:

1. Go to *Sales > Products > Products* and switch to the list view.
2. Select the products.
3. Click *Actions > Generate XML IDs*.

Products that already have an XML ID are left as they are. Odoo shows
how many of the selected products got one.

The XML ID is made once, at creation: it does not change when the
internal reference or the name of the product changes later.

Known issues / Roadmap
======================

- Product variants (``product.product``) get no XML ID of their own.
- Products whose name or internal reference consists of characters
  without an ASCII equivalent only, for example in Chinese, get no XML
  ID.
